# ESPatcher identity

Signal Router is the ESPatcher mark, selected by Alex Matheu. Its white routed
connections and circular badge follow the GlitchDrums / GlitchEffects family.

- `ESPatcher.svg`: editable vector with transparent background.
- `ESPatcher.png`: 1024 px dark-background artwork.
- `../Apple/Assets.xcassets/AppIcon.appiconset`: iOS and macOS icon variants.

The artwork is covered by the repository MIT license.
