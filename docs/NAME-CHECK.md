# ESPatcher public-name check

Checked 2026-11-13 for the proposed open-source instrument loader name.

- GitHub repository-name search returned **0** results, with `incomplete_results: false`:
  https://api.github.com/search/repositories?q=espatcher+in:name
- General exact-name and ESP32/audio searches did not reveal an obvious matching
  synthesizer or firmware-loader project.
- The name is not globally unused: a 2010 Ether Saga toolkit post lists
  `ESPatcher.exe`, an unrelated game-file patching tool:
  https://www.elitepvpers.com/forum/general-gaming-discussion/438656-ether-saga-online-starter-pack.html

This records search findings, not exclusive rights, trademark clearance, domain
availability or a reserved repository name. No public repository or domain was created.

Chosen branding: **ESPatcher** = loader/platform; **AMSynth** = custom instrument
firmware. Existing internal identifiers remain for session/settings compatibility.
